---
id: KB-010
title: Suspected account compromise
tags: security, hacked, compromised, password changed, unauthorized, api key, suspicious login, 2fa
---
If a customer reports a password change, login or API key they did not make:
1. Escalate to the **security** team immediately. Do not troubleshoot through normal support.
2. Security will lock sessions, revoke unknown API keys and help the customer recover the account.
3. Advise the customer to reset their password through the "Forgot password" link and to enable 2FA.
4. Never ask the customer to send passwords or full API keys over support channels.
