## Where to find it
Dark mode is available on **all plans**: Settings > Appearance offers Light, Dark and System Default.

## Only "Light" and "System Default" are shown
Desktop app versions **older than 3.2** do not show the Dark option. Update the desktop app
(Help > Check for updates) to 3.2 or later. The web app always shows all three options.

## Known issue: "System Default" ignores macOS dark mode (BUG-2291)
On desktop app 3.1.x for macOS, System Default does not follow the macOS appearance and stays light.
This is fixed in version 3.2. Workaround: update to 3.2+ or use the web app.
If the problem continues on 3.2 or later, route the ticket to the **product** team with the app version and OS.

## Scheduled theme switching
Switching theme automatically at a set time is **not supported** yet. System Default follows the OS, so users can
schedule dark mode at the OS level (macOS: System Settings > Appearance > Auto).
